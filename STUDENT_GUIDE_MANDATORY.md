# Student Instructions - BBSUL Portal

## Step 1: Go to Portal
URL: http://localhost:5000
Click **Student Login** (purple button)

## Step 2: Login
- Email: your.name@bbsul.edu.pk (as given by admin)
- Password: (as given by admin)
- Click **Login & Continue**

## Step 3: Fill Form (ALL 24 FIELDS MANDATORY)

**All fields are required.** The form will not submit if any field is empty.

### Section 1: Personal Information
| Field | What to Enter |
|-------|---------------|
| Student Name | Your full name as per CNIC |
| Father Name | Your father's full name |
| Gender | Select M, F, or Other |
| Roll Number | Your university roll number |
| Admission Date | Date you were admitted (YYYY-MM-DD) |
| Nationality | e.g., Pakistani |
| CNIC Number | Format: 42303-2678191-2 (auto-formats) |
| Passport Number | If you have one, else still required |
| Date of Birth | Your DOB (YYYY-MM-DD) |
| Phone Number | Mobile number with country code |
| Email | Your email address |

### Section 2: Domicile & Address
| Field | What to Enter |
|-------|---------------|
| Domicile District | Your district name |
| Domicile Province | Your province |
| Mailing Address | Complete postal address |
| City | Your city name |

### Section 3: SSC (Matric) Details
| Field | What to Enter |
|-------|---------------|
| SSC Degree Name | e.g., Matric |
| SSC Board Name | Your exam board |
| SSC Total Marks | Total possible marks (e.g., 1050) |
| SSC Obtained Marks | Marks you obtained |

### Section 4: HSSC (Intermediate) Details
| Field | What to Enter |
|-------|---------------|
| HSSC Degree Name | e.g., FSc, ICS, ICom |
| HSSC Degree Nomenclature | Required: numeric code (1-5) |
| HSSC Board Name | Your exam board |
| HSSC Total Marks | Total possible marks (e.g., 1100) |
| HSSC Obtained Marks | Marks you obtained |

**HSSC Degree Nomenclature codes:**
- 1 = Pre-Medical
- 2 = Pre-Engineering
- 3 = General Science
- 4 = Commerce
- 5 = Arts

## Step 4: Submit
Click **Submit Form** (green button)
You will see: "Form submitted successfully!"

**Important:**
- You can submit **ONLY ONCE**
- Cannot edit after submission
- To resubmit, admin must delete your record first

---

## Troubleshooting

**"Required fields missing"**
- All 24 fields must be filled
- Check for any empty field (including passport number if not applicable)
- Date fields must have a value (use any valid date)

**"Invalid credentials"**
- Verify email spelling
- Password is case-sensitive
- Ask admin to reset

**Need to edit after submit?**
- Ask admin to delete your submission
- Then you can resubmit

**Passport not applicable?**
- Still fill it with "N/A" or "None"
